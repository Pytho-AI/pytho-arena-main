## Conversion rule

Text and tables supply mission purpose, environment, protected asset categories,
threat classes, sensor modalities, response categories, and references. Images and
maps never supply coordinates. For a real installation, the importer replaces exact
geometry, boundaries, marked points, defense placements, patrol zones, coverage
circles, and approach paths with a fictional scene. The import report records each
replacement and requires human approval.
